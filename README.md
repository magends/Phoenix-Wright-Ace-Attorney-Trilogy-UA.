# Ентузіастський українізатор Ace Attorney

⚖️ Phoenix Wright: Ace Attorney Trilogy — Українська локалізація
Напевно, забагато часу пройшло без української мови в грі про адвоката з їжаком на голові. Саме тому, на голому ентузіазмі та за багацько безсонних ночей, презентуємо вам початок перекладу легендарної трилогії!

Поточний статус: Перекладено два епізоди першої гри. Проєкт активно оновлюватиметься.

📝 Про переклад
Це фанатська локалізація, що охоплює не лише текст, а й графічні елементи (спрайти). Ми намагалися зберегти фірмовий гумор та юридичну напругу оригіналу, адаптувавши її під українського гравця.
